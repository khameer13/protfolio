# Portfolio · Mohammed Khameeruddin

Personal portfolio: backend engineer (Node.js, TypeScript, AWS), Bengaluru.

**Live site:** https://khameer13.github.io/protfolio/

## Sections

- About, experience (Aquera, Procify) and skills
- Projects with live demos and code links: TrackMyMeds, Chat Room, Math Quiz, Feedback Aggregation System, FriendVerse, Login Dashboard
- Education and certifications
- Contact: email, LinkedIn, GitHub

## Tech

Plain HTML, CSS and JavaScript — no build step. Responsive, light/dark mode, keyboard accessible, images compressed and lazy-loaded.

## Run locally

Open `index.html` in a browser, or:

```bash
npx serve .
```
