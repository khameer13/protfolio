Login Dashboard

Full-stack web app

  • MongoDB
  • Express
  • React
  • Node.js
  • JWT

Overview

A full-stack web app on the MERN stack (MongoDB, Express, React, Node.js). Users sign up and log in; authenticated users reach a protected home page, an about/profile page and a contact form.

How it works

  • Sign-up and login handled by an Express API, with JSON Web Tokens (JWT) for authentication.
  • User accounts and contact messages stored in MongoDB Atlas.
  • React front end with separate pages for login, sign-up, home, about and contact.
