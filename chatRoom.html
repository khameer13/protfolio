Chat Room

Mini project · 6th semester, MVJ College of Engineering · Jan 2023

  • Node.js
  • Socket.IO
  • WebSockets
  • JavaScript
  • HTML/CSS
Live demo Code Project report (PDF)

Overview

A real-time group chat. Users join with a name, and every message is pushed instantly to everyone else in the room.

How it works

  • A Node.js server runs Socket.IO, which keeps a persistent WebSocket connection open to each browser.
  • The server tracks connected users by socket ID and broadcasts events: someone joined, a new message, someone left.
  • The browser client renders incoming messages on the left, your own on the right, and join/leave notices in the middle.

2026 update

  • Redesigned interface with a join screen, timestamps, typing indicator and online count.
  • Server input limits and safe text rendering; Socket.IO upgraded.
  • Live demo on GitHub Pages: without a server it chats between tabs of the same browser.
