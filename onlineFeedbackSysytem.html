Code Project report (PDF)

Overview

A web app for collecting course and teaching feedback. Students fill in a rating form for their faculty; faculty and the admin see aggregated results instead of handling paper forms.

Features

  • Three roles: admin (manage faculty and students, view all feedback), faculty (view their results, update profile) and student (submit feedback).
  • Feedback is anonymous: the admin cannot see which student submitted which response.
  • Reports are calculated automatically, removing manual tallying errors.

2026 security update

  • All queries moved to prepared statements; passwords stored with password_hash.
  • CSRF tokens, role-based sessions, output escaping and safe image uploads.
