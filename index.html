About

I'm a backend engineer with 2+ years of experience building Node.js and TypeScript services. At Aquera I work on a platform that turns records from HR and identity systems (Workday, ADP, UKG, Dayforce, Okta, Microsoft Entra ID and others) into one joiner/mover/leaver event format, indexed in OpenSearch and evaluated by monitoring rules.

Before that, at Procify (2024–2026), I grew from trainee to backend developer: an OAuth 2.0 secure gateway for SAP integrations, an aggregate query engine, caching for faster responses, and LLM features with LangGraph, FAISS vector search and Neo4j knowledge graphs.

I care about clear API and schema contracts, backward compatibility, tests that prove behaviour, and debugging from evidence.
